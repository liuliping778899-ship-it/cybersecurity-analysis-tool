## Project Description

This project demonstrates how GitHub and Freshworks can be used in a cybersecurity project. GitHub is used for source code control, branch management, commits, pull requests, and documentation. Freshworks is used to record and track security issues.

The project contains two main cybersecurity tools:

1. Security Log Analysis Script
2. Basic Vulnerability Assessment Script

## Project Objectives

- Use GitHub branches to control project changes.
- Write clear and descriptive commit messages.
- Use pull requests to review changes.
- Track cybersecurity issues in Freshworks.
- Analyze security logs for suspicious activities.
- Identify potentially risky open ports.
- Document the complete development process.

## Repository Branches

- `main`: Stable production version.
- `development`: Integration and testing branch.
- `feature/log-analysis`: Log analysis development.
- `feature/vulnerability-scan`: Vulnerability assessment development.
- `feature/documentation`: Project documentation updates.
